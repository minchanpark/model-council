# 심사·통합 루브릭

## 1. 평결표 (심사 체크리스트)

PLAN에서 동결한 기준 ID(C1…)별로 트랙(리서처)별 판정을 표로 만들어 세션 실행 원장에 기록한다(채팅 미출력). 서브에이전트의 자가 채점표는 사전 필터일 뿐 — "충족" 주장도 근거 포인터를 확인해 번복할 수 있다.

```
| 기준 ID | 판정 방법 | 트랙 A | 트랙 B | … | 종합 |
|---|---|---|---|---|---|
| C1 | (기계적 확인 | 정성 판정+사유) | 충족/부분/미충족 — 근거 포인터 | … | … | 충족/미충족 |
```

기준 작성·판정 시 기본 관점:

| 항목 | 통과 기준 | 미달 시 |
|---|---|---|
| 커버리지 | 계획의 핵심 질문에 모두 응답 | 누락 질문만 골라 재질의 |
| 근거 | 핵심 결론마다 출처 또는 [추정] 표시 | "이 주장의 출처는?" 재질의 |
| 최신성 | 시점 민감 주장에 날짜·최근 출처 | 최신 확인 요청 |
| 확신도 | 낮음 표시 항목이 결론을 좌우하지 않음 | 결론 의존도 낮추거나 재검증 |
| 범위 | 브리프 범위 이탈 없음 | 이탈 부분은 통합에서 제외 |

## 2. 모순 판정 순서

1. 정말 모순인가? (범위·시점·정의 차이로 둘 다 참일 수 있음 → 조건 명시로 해소)
2. 근거의 질 비교: 1차 출처 > 2차 보도 > 블로그·추정. 최신 > 과거. 직접 데이터 > 유추.
3. 판정 가능 → 승자 채택 + 이유 1줄. 판정 불가 → 양론 병기 + "확인 방법" 제안.
4. **다수결 금지**: 두 모델이 같은 오답에 수렴할 수 있다. 일치 자체는 근거가 아니다.
5. **입장 배정 트랙의 판정**: 배정된 입장(찬/반)의 결론은 그 방향의 논거를 만들라는 임무의 산물이지 독립 판단이 아니다 — 입장 자체에 가중치를 주지 말고, 양측 **논거의 질**(위 2번 기준)만으로 판정한다. 배정 입장과 반대로 기우는 결론을 낸 리서처의 근거는 오히려 강한 신호로 취급한다.

## 3. 통합 리포트 템플릿

```
# {목표 한 문장에 대한 답}

## 결론
(성공 기준을 모두 충족하는 직접 답변. 3~7문장)

## 근거 종합
### {주제 1}
- ... (Codex)
- ... (양쪽 일치)

## 모델 간 불일치와 판단
| 쟁점 | Codex | Claude | 판정 |
|---|---|---|---|

## 남은 불확실성
- ...

## 출처
- ...

---
council: codex({model}, {requested→actual effort}) + claude({model}, {tier→profile effort}) | followups: N회({종료 사유: 충족|정체|캡})
```
