# 심사·통합 루브릭

## 1. 심사 체크리스트 (리서처 결과별)

| 항목 | 통과 기준 | 미달 시 |
|---|---|---|
| 커버리지 | 계획의 핵심 질문에 모두 응답 | 누락 질문만 골라 재질의 |
| 근거 | 핵심 결론마다 출처 또는 [추정] 표시 | "이 주장의 출처는?" 재질의 |
| 최신성 | 시점 민감 주장에 날짜·최근 출처 | 최신 확인 요청 |
| 확신도 | 낮음 표시 항목이 결론을 좌우하지 않음 | 결론 의존도 낮추거나 재검증 |
| 범위 | 브리프 범위 이탈 없음 | 이탈 부분은 통합에서 제외 |

## 2. 모순 판정 순서

1. 정말 모순인가? (범위·시점·정의 차이로 둘 다 참일 수 있음 → 조건 명시로 해소)
2. 근거의 질 비교: 1차 출처 > 2차 보도 > 블로그·추정. 최신 > 과거. 직접 데이터 > 유추.
3. 판정 가능 → 승자 채택 + 이유 1줄. 판정 불가 → 양론 병기 + "확인 방법" 제안.
4. **다수결 금지**: 두 모델이 같은 오답에 수렴할 수 있다. 일치 자체는 근거가 아니다.

```
### {주제 1}
- ... (Codex)
- ... (양쪽 일치)

## 모델 간 불일치와 판단
| 쟁점 | Codex | Claude | 판정 |
|---|---|---|---|

## 남은 불확실성
- ...

## 출처
- ...

---
council: codex({model}, {requested→actual effort}) + claude({model}, {tier→profile effort}) | followups: N회
```
