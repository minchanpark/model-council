# council-retro 제안 원장 (council-retro-proposals.md) 양식

> 이 파일은 작업 폴더에 누적되는 **제안 원장**이다. retro는 여기에 추가만 하고(덮어쓰기 금지), 사람이 채택/기각 상태를 갱신한다. 기각 항목은 다음 retro의 재제안을 막는 버퍼가 된다.

## 제안 양식

```
### R-{번호} [상태: 제안|채택|기각|보류]
- 유형: add | delete | replace
- 대상: {파일} § {절}
- diff: (변경 전 → 변경 후, 최소 단위)
- 근거: {state 파일 인용 + 발생 런 수, 예: "5런 중 3런에서 재질의가 C-근거 기준에서 정체"}
- 개선 지표: {SKILL.md §6 목록 중 하나}
- 적용 범위: 공통 | claude | codex | {프로바이더}
- 순증 토큰: {+N자 / 0 / -N자}  (0 목표 — 추가 시 압축·삭제 동반)
- 자기완화 여부: 아니오 | ⚠예
- (기각 시) 기각 사유:
```

## 원장 섹션 구조

```
# COUNCIL RETRO — 제안 원장

## 활성 제안
(상태: 제안|보류 인 R-번호들)

## ⚠ 자기 완화 — 특별 검토
(루프 규율을 완화하는 제안. 데이터 정당화가 있어도 사람의 특별 검토 필요)

## 기각 이력 (재제안 금지 버퍼)
(상태: 기각 인 R-번호 + 기각 사유. 다음 retro가 LOAD에서 먼저 읽는다)

## 채택 이력
(상태: 채택 인 R-번호 + 반영 커밋/버전. 사후 지표 평가 대상)
```

## 예시 (문구 교정 — 단일 근거 허용)

```
### R-1 [상태: 제안]
- 유형: replace
- 대상: skills/orchestrate/SKILL.md § 3 재질의 루프
- diff: "정체 — 직전 라운드 대비 미충족 수 미감소" → "정체 — 직전 라운드 대비 미충족 수가 줄지 않음(동수 포함)"
- 근거: 3런에서 "미감소"를 "감소 안 함"과 "0"으로 다르게 해석한 흔적(마찰 기록)
- 개선 지표: 정체 발생률
- 적용 범위: 공통
- 순증 토큰: +6자 (대상 문장 내 치환, 순증 최소)
- 자기완화 여부: 아니오
```
